# 洞察 02 · 公开 benchmark 的 100% 为什么是假信号

> DeepSeek 在两套公开 CS 题上各拿 100%，在自建的 8 道 IRIS 私有题上只拿 62%。
> 哪个才反映它在这个领域的真实能力？—— 62%。

## 现象

| 题集 | 类型 | 样本 | DeepSeek |
|---|---|---:|---:|
| mmlu_cs | 英文 CS 公开题 | 5 | 100% |
| ceval_cs | 中文 CS 公开题 | 5 | 100% |
| **IRIS 私有题** | 自拟领域题 | 8 | **62%** |

## 公开题的 100% 为什么不可信

两个独立缺陷，任何一个都足以让这个 100% 失真：

1. **gold 分布严重偏斜。** 这次抽的 mmlu_cs 5 道里有 4 道 gold = B，ceval_cs 同样 4 道 gold = B。一个什么都不做、每题都蒙 B 的策略能直接拿 80%。样本量 5 + gold 集中，分数的统计意义接近零。
2. **可能的训练污染。** MMLU / C-Eval 是广为流传的公开题集，极可能在模型训练时见过原题。见过原题的"100%"不等于会做这类题。

→ **100% 至少要打个对折。** 它既可能是真会，也可能是 gold 偏斜 + 见过原题的叠加。

## IRIS 私有题的 62% 才是真信号

私有题（见 [`private-eval/iris_mcqa_8.json`](../private-eval/iris_mcqa_8.json)）gold 均匀分布（A2/B2/C2/D2），且题目由作者自建数据集改写、不照搬公开题，污染风险低得多。

DeepSeek 错的 3 道（Q1/Q2/Q5）有一个高度一致的特征：

| 错题 | 领域 | 模型选的干扰项 | 干扰项为什么"像对" |
|---|---|---|---|
| Q1 | SQL 存储过程命名 | `CLASSNAME.METHODNAME` | 符合 Java/Python 的包.类.方法直觉 |
| Q2 | SQL 全限定表名 | `User.Person`（原样类名） | 符合大多数数据库"类名即表名"的直觉 |
| Q5 | 断点模式函数 | `$SYSTEM.Debug.Break()` | 符合现代面向对象 API 直觉 |

**模型不是在乱猜，它答的都是「符合通用编程语言直觉、但对 IRIS 这套特定规则不适用」的选项。**
这暴露的是一个真实的能力边界：**有泛化的编程知识，但缺 IRIS 精确的 API / 命名规则。** 38% 的差错是真差，不是题目设计问题。

## 出题时学到的三条

1. **最有效的干扰项是「通用直觉项」。** 让模型在"通用规则"和"本领域特定规则"之间站队，最能暴露领域偏置。干扰项太离谱（"无 / 未知 / 不适用"）反而让模型秒答对，题目作废。
2. **gold 必须均匀分布。** 这次公开题的 4/5 偏 B 是反面教材。出题时要保证答案选项均匀，否则分数被抽样偶然性主导。
3. **「私有」是相对概念。** 自建改写能降低污染，但不能保证模型训练时绝对没见过相似内容。真正的"私有"得用训练截止后的新事件或纯个人经验题。

## 这说明什么

> **公开 benchmark 负责横向比较，私有题库负责业务决策，两者不可互替。**

- 公开题（MMLU / C-Eval / GSM8K）：口径公开、可和别家模型对齐，适合做选型初筛。
- 私有题库：贴合你的真实业务、能暴露领域边界，是"能不能上线"的决策依据。

如果你要判断「DeepSeek 能不能做 IRIS 运维助手」，看 mmlu_cs 的 100% 没用，看 IRIS 私有题的 62%（以及错的 3 道都错在哪）才有用。

## 证据强度（重要边界，与[洞察 01](01-extractor-gap.md) 不同）

- **洞察 01 可独立复算**：GSM8K 逐题 responses 已固化在 `data/`，`replay.py` 能重算 64% / 98%。
- **洞察 02 是观察性结论**：mmlu_cs / ceval_cs / IRIS 私有题的结果来自课程作业的自研 runner（zero-shot、直接比较 A/B/C/D），**逐题原始 responses 没有固化在本仓库**，不能在此独立复算。本仓库只公开了 8 道 IRIS 题目本身（`private-eval/iris_mcqa_8.json`）和它们的 gold + DeepSeek 预测，作为可检查的题目样本。
- **8 道题样本量过小，不能用于任何模型排名。** 这里的 62% 只用于展示「公开题满分 / 私有题露馅」这一现象，不构成对 DeepSeek 在 IRIS 领域能力的裁决。
- gold 由作者判定，未经过独立领域专家复核；错题归因是观察性结论，非金标裁决。
